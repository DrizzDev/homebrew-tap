# homebrew-tap

Homebrew packages for Drizz tools.

```bash
brew install DrizzDev/tap/drizz          # drive connected devices from AI assistants and the command line
brew install DrizzDev/tap/twin-harness   # test an AI agent against a Drizz twin and grade what it actually did
```

Installing either one taps this repository; after that `brew upgrade` keeps both current.

| | kind | source of the download |
|---|---|---|
| `drizz` | cask — prebuilt binary per platform | [DrizzDev/releases](https://github.com/DrizzDev/releases), tags `v*` |
| `twin-harness` | formula — pure Python, built on install | [DrizzDev/releases](https://github.com/DrizzDev/releases), tags `twin-harness-v*` |

`Casks/drizz.rb` is generated by GoReleaser on each drizz release; don't edit it
by hand. `Formula/twin-harness.rb` is updated by hand from the output of
`release.sh` in the twin-harness repository.
